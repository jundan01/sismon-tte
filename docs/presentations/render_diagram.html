🔒 3. Highlight Arsitektur & Tata Kelola SPBE
Security & Compliance

🛡️ Zero-Trust VPN Gateway & Stealth Defense

Seluruh endpoint administratif (/gateway/login dan /admin/*) hanya dapat diakses melalui subnet resmi VPN Diskominfo. Akses dari IP luar menghasilkan respon HTTP 404 Not Found murni untuk mengaburkan sistem dari bot scanner.

🔍 Perlindungan Data Pribadi (UU PDP No. 27/2022)

Data NIK 16 digit dan NIP 18 digit dienkripsi tingkat kolom menggunakan AES-256-CBC deterministik dan diindeks menggunakan HMAC-SHA256 Blind Indexing. Storage browser (sessionStorage) steril dari data sensitif NIK/NIP.

⚡ Unbuffered Cursor Streaming Mass Export

Ekspor jutaan baris CSV/Excel menggunakan single query leftJoin()->cursor() bebas N+1 query dengan konsumsi RAM PHP konstan di bawah 20 MB tanpa resiko Out-of-Memory (OOM).

⏰ Daily Proactive Scanner (00:01 WIB)

Background job harian otomatis mendeteksi sertifikat yang memasuki zona kritis H-3 (WARNING_H3) dan kedaluwarsa (EXPIRED) untuk menjamin kelancaran penandatanganan dokumen dinas.
